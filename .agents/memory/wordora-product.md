Wordora serves Arabic-speaking learners. Keep explanations, meanings, and learner-facing guidance in Arabic. The target languages are English, French, Spanish, German, Italian, and Turkish (explicitly requested). A1 starts open; higher levels unlock through lesson completion.

**Why:** The user specified these as product requirements; they define the audience and supported learning scope.

**How to apply:** Keep future content and UI Arabic-first. Do not replace the target languages or level progression without an explicit request.

The user explicitly approved **A1:100, A2:150, B1:200, B2:250, C1:300, C2:350 learning entries per language**, not per lesson. All six levels must exist in every supported language, including Turkish, ordered A1 → A2 → B1 → B2 → C1 → C2. Higher levels emphasize complete sentences, nuanced expressions and advanced communication rather than extra basic words.

**Why:** The user repeated that a small four/six-word expansion was insufficient, insisted all languages receive the changes, and selected these per-level counts after clarification.

**How to apply:** Distribute the content into short interactive lessons without deleting existing IDs/progress. Show level totals separately from the smaller lesson word counter; preserve the agreed quantities when editing the curriculum.

Keep the interface visually calm and avoid showing every secondary control or
long lesson list at once.

**Why:** The user explicitly found the site's layout too dense to look at and
asked for clearer organization, while keeping the existing product functional.

**How to apply:** Give each page a clear primary task, group related content,
and progressively reveal secondary options without removing access to them.

The educational assistant's display name is **GPT Ieon**, and it belongs centrally on the learning page.

**Why:** The user explicitly confirmed this name and placement after clarification. It is a product name, not a requested model identifier.

**How to apply:** Preserve the exact spelling and Arabic-first tutoring role when changing chat providers or redesigning the learning experience.

Keep the supplied Wordora logo as the first thing shown when the app opens, including for returning users. Preserve the existing brand colors and working features during additions.

**Why:** The user repeated the logo-first requirement and explicitly requested preserving the current identity and real functionality.

**How to apply:** Do not substitute a new mark, hide the opening logo for signed-in learners, or replace working learning tools with decorative mockups.

Lessons should show one word at a time; a full vocabulary list belongs in the end-of-words summary. Remember the learner's place without awarding points for navigation. Use only content-matched playable videos, and give an honest audio/example alternative where none exists.

**Why:** The user explicitly chose this learning flow and rejected stacked word lists, fictional videos and broken links.

**How to apply:** Preserve next/previous navigation, resumable study and a separate quiz step when extending lessons.
